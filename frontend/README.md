# ASWired 网站

ASWired 的固定深色管理网站，使用 Svelte 5、SvelteKit 与 Bits UI。默认连接真实主控，数据库为空时显示初始化或空状态；不存在自动填充演示服务器、伪造任务成功或客户端切换角色的入口。

## 本地开发

使用 Node.js 24、pnpm 11.19.0，以及运行中的 ASWired Server。依赖以提交的 `pnpm-lock.yaml` 为准。

```sh
npm install --global pnpm@11.19.0
pnpm install --frozen-lockfile
pnpm dev
```

默认访问 `http://localhost:5174`。开发服务将 `/api`、`/mcp` 与 `/.well-known/webauthn` 代理到 `http://127.0.0.1:12889`。使用 `ASWIRED_API_TARGET` 环境变量可切换到独立测试主控；该变量只用于开发代理，生产网站通过同源反向代理连接主控。

首次使用从主控数据目录的 `setup-token` 文件读取初始化令牌，在页面创建管理员。不要将该文件、数据库、Agent 配对配置或真实令牌提交到仓库。

## 探针入口

侧栏「探针监控」和工作区搜索中的同名入口直接打开 Komari 探针首页；旧 `/probe` 链接也会跳转。地址取自主控的 `ASWIRED_KOMARI_PUBLIC_URL`，未配置时显示错误及重试入口。原内置展示页不再出现在主站中，「Komari 管理」仍保留管理员后台登录功能。

## Agent 批量升级

升级窗口提供“全选可升级节点”、取消全选和数量统计。只选择在线、启用 `agent_update` 且没有未完成升级的 Agent；状态变更会移除不再满足条件的选择，提交成功的节点会标记为已提交。旧服务未启用升级监督进程时，窗口明确提示需保留配置与数据，以 `-supervise` 启动服务后刷新状态。Komari 探针在线不能替代 ASWired Agent 的升级能力；不同架构仍须分批选择对应制品。

## 服务器监控视图

`/servers` 默认显示监控卡片，可切换回列表；布局偏好只保存在当前浏览器。两种视图共用搜索、状态筛选、分页与管理权限，工具栏间距一致，内容区保留两种布局所需的高度；隐藏视图不参与焦点或辅助技术导航，切换时分页栏不会因布局高度差跳动。卡片沿用全站暖灰配色，显示所选探针实际提供的 CPU、内存、磁盘、运行时长、实时网速与双向累计流量；缺失和离线指标不会补零。地区使用本地 SVG 国旗，优先手动地区，再使用探针地区。

主机流量按十进制 GB 计算，与 Xray 代理计费台账独立。只有已配置月度重置、且月度元数据仍绑定当前 Komari UUID 的记录，才显示账期进度、剩余额度与重置时间；其他记录显示累计流量。`trafficPeriod=monthly`、`trafficResetDay`、`trafficResetTimezone=Asia/Shanghai` 与 `trafficPeriodKomariUUID` 是已完成 Agent 配置的记录，不会由前端自动设置，也不能代替 Agent 的实际月重置。当前显示支持 1–28 日，超过额度的用量保留，进度条最多填满。

卡片的延迟与丢包区目前保留无数据状态，网络质量历史仍从探针历史页查看。未提供网络质量采样时不会绘制虚构曲线。卡片详情、编辑、配置发布与删除使用原有真实主控接口；没有本地示例角色或演示数据入口。

## 独立本地主控联调

要与其他开发实例隔离，在构建主控后，从网站仓库的两个 PowerShell 终端分别执行：

```powershell
./start-controller.ps1 -ListenAddress '127.0.0.1:12890' -PublicUrl 'http://localhost:5175' -DataDirectory '../ASWired-Server/data-local-test'
./start-preview.ps1 -Port 5175 -ApiTarget 'http://127.0.0.1:12890'
```

访问 `http://localhost:5175` 完成初始化。使用新的数据目录和本地 Agent 配对配置，不导入生产数据库或生产集成设置；运行数据、账户和密钥不能提交 Git。Agent 连接本机地址后，服务器卡片应显示实际 Windows/macOS/Linux 主机指标，页面每次自动刷新读取真实接口。

## 认证与数据

- 网站使用主控签发的 JWT，位于浏览器 sessionStorage，通过 `MM-Authorization` 发送。普通成员与管理员权限由服务端验证。
- 密码、TOTP、恢复码、Passkey 与 Telegram Mini App 最终接入同一 JWT 身份。
- 扫码登录生成两分钟有效的二维码。已登录手机扫码后须填写原浏览器的六位确认码并明确确认；新 JWT 仅发给持有独立轮询凭据的原浏览器，二维码及手机确认响应不包含 JWT。过期、取消和已消费请求不能重用。
- API Token 在账户安全页面单独创建，通过 `Authorization: Bearer` 用于 API/MCP。明文只显示一次。
- 列表读取脱敏状态，编辑或配对时才请求授权详情。保存、删除、应用必须收到真实后端结果；Agent 未连接时任务保持等待或返回具体错误。
- Reality 编辑可读取必要的私钥、派生公钥和 Short ID；弹窗通过底部操作或 Esc 关闭，不显示右上角 ×。

### REALITY 目标池

`/reality-targets` 仅供管理员管理握手目标。管理员先配置精确域名允许列表，添加目标后，从主控实际连接目标的公网 443 端口，验证 TLS 1.3、h2 协商和域名证书。探测结果记录实际连接 IP、TCP / TLS 耗时及证书到期日；批准需要最近 15 分钟内的成功探测。私网、回环及保留 IP 均不可探测，DNS 解析后固定连接已校验的公网地址。

普通成员不显示目标池菜单与搜索入口，直接页面访问和目标池接口均禁止，也不能提交贡献。只有允许列表内、已审核启用且证书未到期的目标进入 Reality 编辑下拉框，选择后填写 Target 和 SNI。管理员可停用、重测、拒绝或删除目标；已保存入站中的地址不会被自动替换。

### 登录验证与静默入口

设置中可启用 Cloudflare Turnstile，填写站点密钥、私密密钥和允许的主机名。登录组件固定深色，以 `login` 动作完成验证；主控校验来源、时效和一次性令牌。自测成功后再启用生产配置。

静默模式需配置至少 24 位的入口密钥。访问 `/entrance/你的入口密钥` 后，网页先从地址栏删除密钥，再由主控验证并设置短期入口 Cookie，随后进入工作区登录页（已登录则进入总览）。入口 Cookie 只打开入口，管理操作仍需 JWT。没有有效入口或会话的常规入口显示 404；已保存的 JWT 会在首个状态请求携带，避免合法会话被隐藏入口挡住。入口密钥属于秘密，不应放进公开文档、监控 URL 或分享截图。

```sh
pnpm check
node --test tests/*.test.mjs
pnpm build
```

生产输出使用 `@sveltejs/adapter-node`，运行方式为：

```sh
ORIGIN=https://panel.example.com HOST=0.0.0.0 PORT=3000 node build
```

## Docker 与反向代理

```sh
docker build -t aswired-web .
docker run --rm -p 3000:3000 -e ORIGIN=https://panel.example.com aswired-web
```

从 `frontend` 目录执行构建。Dockerfile 使用 Node.js 24 和固定的 pnpm 11.19.0，构建与生产依赖均通过 `--frozen-lockfile` 安装；运行镜像只复制生产依赖、应用元数据和 Node 构建产物，以非 root 用户运行。镜像构建需要访问镜像仓库和依赖注册表，不会连接用户的主控或创建账户。

`deploy/nginx.conf.example` 展示 Node 网站与主控的同源代理方式；示例中的 `web` 和 `server` 是容器网络服务名，须按实际部署替换，原生部署使用对应监听地址。还需替换外部域名并在入口配置 HTTPS。主控 `ASWIRED_PUBLIC_URL` 应等于外部网站地址；`ASWIRED_ALLOWED_ORIGINS` 必须包含主站及获授权的独立探针来源。

反向代理须保留 `Origin`，传递登录头，并允许 Agent/WebSocket 升级。备份上传直接代理到主控，按示例配置请求大小与超时。Passkey 的 RP ID 与允许来源应使用最终 HTTPS 域名；域名改变时已有通行密钥不会自动迁移。

## 套餐与扩展

套餐管理可开放成员申请，管理员人工核对后发放；兑换码支持批量、次数、期限与吊销。成员的续期声明不代表收款成功，人工核对后才延长期限。用量重置移动当前计量窗口，保留历史账本。合并订阅保留各套餐独立凭据和额度，不声称复刻未公开的冲突算法。

临时订阅从当前账户的有效套餐选择单个节点，期限为 1 分钟至 7 天、下载次数为 1–1000 次，且不能晚于原套餐到期。完整链接只在创建时显示一次，可在列表撤销；原套餐令牌轮换后对应临时链接失效。每次下载重新检查套餐、额度、节点范围和白名单，成功渲染后原子扣次，格式失败或 HEAD 请求不扣次。网络中断发生在成功渲染和扣次之后时，本次次数仍已使用。

临时配置复用正式订阅的客户端格式转换器和本人节点凭据，仅输出所选节点的标准规则，不携带可能扩展节点范围的模板与脚本。次数和期限限制的是后续下载，不会删除用户已下载的配置；实际网络使用继续受原套餐的有效期、额度和节点策略约束。不能用临时链接登录管理工作区。

成员仅可查看有效订阅授予的节点列表并测速，节点新增、编辑和删除由管理员负责。外部订阅仅管理员可用，成员不显示菜单和搜索入口，直接页面访问及读取、新增、编辑、删除、同步接口均禁止。个人订阅管理和临时订阅继续可用。

扩展页连接实际的节点分享、Nginx 配置、Cloudflare DDNS 与家用测速端。证书配置支持 ACME 所需字段、人工上传和部署；网络操作需要用户自行提供有效地址和授权凭据。仅外部探针适配 Komari `1.2.5-fix2`；服务器可显式选择原生或 Komari 数据源并关联 Komari UUID，不做隐式故障切换。

家用测速端可生成 10 分钟有效的一次性配对码，通过 Agent 的 `-pair-url` / `-pair-code` 消费；配对信息不含用户 JWT。家用端本机须预配置固定的 mihomo 二进制及 SHA256。连接凭据轮换会创建真实下发任务，旧身份只有 15 分钟宽限，页面提供任务链接核对端点持久更新结果。

### Agent 管理、网络操作与限制

- Agent 管理分享使用拥有方签名授权及明确的命名空间、入站别名和动作白名单。消费者先复制本机公钥给拥有方，拥有方等待 Agent 身份确认后发布；Agent 安装授权的任务完成后，消费者才能接入。命令响应提供请求标识供读取实际结果，撤销也有 Agent 更新任务。
- 转发支持 TCP / UDP 规则与 2–8 跳链，页面显示每台服务器的任务链接。WireGuard 与 WARP 使用用户提供的有效隧道配置；WARP 操作不注册外部账户。Xray 固定为内嵌模式，外部模式与迁移入口已删除。这些动作会改变目标网络状态，须查看 Agent 的真实执行结果。
- 周期网络质量通过服务器 `networkQualityTargets` 配置。探针历史支持 CPU、内存、磁盘、网卡和管理员明确公开的网络质量数据。TCP 连接失败率与 ICMP 丢包分别标注，缺少历史采样时曲线断开。
- 探针自动刷新时保留当前历史曲线，新响应到达后替换；临时网络或服务异常显示上次数据与更新失败提示。切换服务器、指标或时间范围会独立加载，旧响应不能覆盖新选择。主控明确关闭公开展示或撤回访问时清除缓存，确认没有历史记录时显示空状态。
- 探针设置的 `showGlobe` 与 `showAssets` 分别控制球面位置图和续费时间轴，主站与独立探针共用同一组件。地球支持拖动旋转，只绘制服务器明确填写的有效 `latitude` / `longitude`，不根据地域猜位置，不加载外部地图。时间轴按 `expires_at` 排序，原样展示 `renewal_price` / `renewal_currency` / `renewal_cycle` 与 `provider_name` / `provider_url`；缺少到期日或金额不使用演示数据补全。这些字段开启展示后会公开。
- 运维分组仅管理员可见和访问，包括流量分析、限速与事件、证书与域名、任务与发布、通知中心、审计日志及扩展能力。侧栏、页面搜索、快捷入口和直接地址使用相同权限；主控同时限制运维接口，成员仍可查看自己的套餐与订阅用量。
- `/limits` 供管理员查看有效下载限制、采样有效性、节点执行确认及事件。全局、套餐和成员可编辑行为规则；套餐实例可覆盖超额停止或降速。配置规则和节点已执行是两个状态，不以保存成功代替执行确认。
- 任务详情通过管理员接口读取完整 JSON 结果，可能含配置凭据。普通成员不能读取任务列表、详情或执行结果；订阅节点测速在节点页面提供结果反馈，外部订阅操作仅向管理员开放。

通知设置提供 Telegram Webhook 设置、删除、状态读取及命令菜单更新，页面展示 Telegram 返回的实际响应。自动通知事件使用服务端真实事件键：`account.login`、`task.failed`、`subscription.changed`、`subscription.unavailable`、`limit.trigger`、`limit.release`。开关只决定事件投递，投递是否成功以记录为准；本地开发地址无法作为 Telegram 公网 Webhook。

IP 数据库设置支持不超过 32 MiB 的 MMDB 上传或 HTTPS 下载。下载需要用户提供来源公布的 SHA256，最多保留三个版本；上传或下载不会自动切换生效版本。IP 查询使用当前启用的本地文件，页面只展示地区、网段、时区和网络组织等指定字段。当前启用版本不能删除，需先切换到另一版本。

自定义 CSS 在外观设置中保存，通过 `style.textContent` 应用。页面固定深色且无主题切换；样式导致页面不可用时访问 `/settings?nocss=1`，清空或修正自定义 CSS。

## 独立探针与 Worker

独立探针复用现有 UI，使用独立静态构建，带一次性 code + PKCE 登录回接。部署步骤和安全边界见 [worker/README.md](worker/README.md)。

```sh
node node_modules/vite/bin/vite.js build --config vite.probe.config.ts
```

静态输出为 `worker/public`。构建不会发布任何站点；Cloudflare 部署需要自行配置来源和账户。Worker 仅代理探针与登录回接所需路径，不暴露主控管理接口。

## 节点测速

节点库每行提供「测速」，顶部提供「一键测速全部」。测量主控到节点的 TCP 连接延迟（包含 DNS 解析），显示最多两位小数；该结果不代表代理握手成功或下载带宽。批量覆盖当前账户可测速的所有节点和分页，顺序执行、单项失败继续，可停止；成员仅可测试有效订阅包含的节点。失败会清除旧延迟，自建节点或订阅源同步在地址与端口不变时保留测试结果，停用状态不会被测速启用。

## 隔离浏览器验证

主控测试目录提供显式启用的 `TestUIFixture`，仅监听 `127.0.0.1:12890`，使用临时数据库和测试账户。配合 `ASWIRED_API_TARGET=http://127.0.0.1:12890`、前端端口 5176 使用。普通测试不会启动它；不要对真实数据库运行 UI 测试或设置测试账户。

## 成员节点可见范围

普通成员的节点库只显示其有效订阅实际允许分发的节点，与正式和临时订阅使用同一范围。过期、停用或流量耗尽且停止服务的订阅不再提供节点；多个有效订阅的节点合并去重。历史导入节点不会仅因属于该成员而绕过套餐与订阅的节点选择。

成员可查看节点列表和测速，不能打开详情、新增、编辑或删除节点；管理员继续维护全部节点。节点名称对成员显示为普通文本，列表不提供详情按钮或详情链接。主控仅向成员返回列表必要字段，节点详情接口及 MCP 详情工具仅管理员可用，订阅配置下载保持原有权限。

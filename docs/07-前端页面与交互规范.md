# 前端页面与交互规范

> 早期业务草案说明：本文仍保留旧版业务模型或原型交互供参考。自行提出的车主/多租户、AA账本、人工审批及付款流程不是本轮新增要求；角色、套餐和续费等实际行为以[第15份当前矩阵](15-完整功能与PRO对齐矩阵.md)及固定版本核对为准，不据旧稿另设流程。

## 视觉与技术栈

使用 SvelteKit、Svelte 5、TypeScript、Tailwind CSS 4、Bits UI、Lucide Svelte，保留前一个 AcoFork 项目确认的配色、字号、字体与侧栏比例。当前站点是独立源代码，非复制构建产物、iframe 或远程网站代理。

视觉 token：背景 `#1b1b19`、侧栏 `#141413`、卡片 `#282826`、文字 `#faf9f5`、次要文字 `#b0aea5`、珊瑚强调 `#cc785c`。根字号 15px，侧栏 240px，页标题 33.75px/37.5px，卡片圆角约10px。正文 Inter Variable、标题 Lora Variable，中文走本地字体回退。纯色背景，不加动态背景。全站固定深色，不支持白天模式或主题切换，也不跟随操作系统外观。读取旧版演示备份时忽略主题偏好，保留业务数据；页面与弹窗使用同一套深色变量。

采用左侧分组导航、紧凑顶栏、标题/操作区、资源内容区；管理员/成员/公开页在展示项目中可相互切换。真实系统必须分认证和公共布局，不能仅依靠菜单隐藏。桌面多列，手机侧栏抽屉、指标双列/单列、表格局部横滚。弹窗用 Bits UI Dialog 管理焦点、Esc 与标题关系。

## 状态与交互规范

资源查询有加载、空结果、错误、过期/未知状态；真实查询失败保留上次数据并标注更新时间。长任务至少展示目标总数、已生效、待同步、失败、可重试原因。破坏性/敏感变更提供影响范围和版本预览，授权范围内可直接执行的普通变更不反复确认。

表格提供搜索、筛选、页码、行详情和导出；URL 保留详情入口。输入字段使用可见标签、范围提示和错误文本。对比配置时隐藏 secret 值，只展示发生变更的字段和凭据指纹。移动端操作按钮不依赖悬停。

下拉框统一使用基于 Bits UI 的共享 `components/Select.svelte`，对齐 [AcoFork 创建页](https://www.acofork.com/create/) 的实际下拉菜单：触发器高 `2rem`、圆角 `.5rem`，浮层与选项圆角 `.7rem`，灰色悬停高亮、选中项右侧勾选。通过 Portal 显示在弹窗上方，支持方向键导航、回车选择和 Escape 关闭；动态选项按 `value` 去重。

设计将设置分为自有探针、展示部署与登录、外部探针接入三组；第三组固定 **Komari / 1.2.5-fix2**，前两组支持内置及独立自有页面与回接，详见[第18份设计](18-自有探针与登录回接设计.md)。当前原型提供面板地址样例、服务端凭据引用、公开开关及 CPU/内存/网卡速率展示开关；公开页使用独立合成指标，包含 3 台在线和 1 台过期样例，缺失指标显示“未知”。原型只保存演示配置；真实 API Key 不进入浏览器本地存储，不将服务器费用作为公开字段。

生产设计另包含服务器 UUID 映射、版本校验、认证与连接状态，尚未实现。版本未知、不匹配、连接失败和数据过期须明确区分，演示操作不能显示“真实连接已验证”。自有探针提供1h/6h/24h历史；Komari来源按验证可读数据和本地采样历史呈现缺口；Xray 管理接入说明与 Komari 探针说明分开。

## 前端工程结构

`src/lib/App.svelte` 管理布局与页面入口；`navigation.ts` 管理导航；`components/EntityPage.svelte` 提供资源列表/表单/详情；`modules.ts` 声明资源字段；`pages/` 包含订阅、套餐、拼车、配置编辑等场景；`store.svelte.ts` 管理本地演示状态；`data.ts` 全是合成数据；`webmcp.ts` 注册三个可选演示工具。

真实 API 接入时新增独立 service/repository 层与结构化 DTO，替换通用 Row 演示模型；状态以服务器 version 和 operation 投影为准。客户端不得计算最终价格、授予权限或决定配额事实。样例 store 不能直接提升为生产账本。

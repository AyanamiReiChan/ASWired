# ASWired 当前实施范围

范围版本：`2026-09-20-agent-connection-modes`。本文件记录用户最新确定的接入范围；与早期设计草案冲突时，以本文件为准。具体实现程度仍以 [实现核对](reference/implementation-audit.json) 和当前代码为准。

## 主控流量设计原则与 Agent 日志（2026-09-20）

- 主控以**最小程度消耗 Agent 服务器流量**为设计原则；必要心跳、准确计量和任务控制保持正常。优先按需、限量、复用已有结果，避免页面轮询造成重复的 Agent 请求。详细约束见 [主控后端设计](19-主控后端详细设计.md)。
- 手动同步默认读取最近 **100 行**，行数限制随请求传至 Agent，在远端截取后返回；不下载整份日志再由浏览器截取。需要更多记录时由用户选择更大行数，仍受 2000 行与 2 MiB 读取预算限制。
- Agent 日志页中的 Agent、Xray 访问、Xray 错误日志均仅通过“同步日志”或“同步日志文件”按钮读取。进入页面、切换服务器/类型/行数、等待和全局自动刷新不会拉取 Agent 日志。
- 界面显示本次文件快照及最近同步时间；切换范围清除旧快照并等待手动同步，不额外持久化日志副本。清理操作直接使用 Agent 返回的文件内容与清单，不追加读取；清理失败则清除旧快照，由用户手动同步确认。
- 系统、定时任务和安全日志读取主控本机文件，可继续自动刷新。

## 节点页 Tunnel 管理（2026-09-20）

- 节点页的 Tunnel 入口直接打开管理弹窗；以隧道卡片显示名称、入口到目标、协议，内部转发链跳点不重复列出。转发记录独立于节点列表。
- 隧道配置提供端口转发与 2–8 跳链式转发表单，端口转发支持 TCP、UDP 或两者；链式转发沿用单协议发布接口。中转配置管理外部已完成的转发映射，独立保存原节点与入口地址；不配置 WireGuard / WARP，也不下发 Agent 任务。
- 每个节点最多配置一个外部中转入口；节点列表、生成订阅、复制连接和测速使用中转地址，凭据和 REALITY 参数保持原值。删除映射后新生成的连接恢复原地址，已下载客户端需刷新订阅。原节点地址变化时旧映射自动失效，需重新添加。
- 延迟探测仅在手动点击时执行，每个实际链路发起一次任务、每次 3 个样本；TCP 检测目标端口，UDP-only 隧道使用 ICMP 检查目标主机可达性，不能据此判断 UDP 服务可用。
- 删除先检查链式发布状态，再逐个等待 Agent 停用成功，最后删除转发记录。失败时保留配置和任务入口；中途已成功停用的跳点可能保持停用，可核对结果后重试或重新应用。

## 节点测速工作台（2026-09-20）

- 节点测速在宽屏弹窗内完成，提供测速来源、1/8/16/32/64 线程、1/4/8/16 MiB 总量、协议/来源标签筛选、可见项选择、单节点/批量测试、仅测延迟和来源隔离的历史记录。
- 数据量是每节点所有线程共享的下载正文总上限，最长 30 秒，握手和出口查询另计；延迟使用代理 HTTP HEAD 请求，不执行下载循环。进入页面、切换选项与刷新状态不启动测速。
- 仅新版本测速端上报 speedtest_bounded 后才允许限量测试，旧版/离线端明确不可用。主控来源由部署在主控机器、source_mode=controller 的已配对测速端提供；未配置时显示不可用，不使用主控直连结果替代代理测速。
- 排队、完成与失败记录保存在主控 speedtests 集合，关闭重开仍可见；受管节点依旧验证套餐范围并使用该实例凭据。外部中转入口继续用于测速。现有 VLESS TCP REALITY 支持范围不变。

## 服务器接入规则

- 服务器只通过 **ASWired Agent** 接入。网站和主控移除面板 API 接入实现、凭据配置与操作入口。
- 新增服务器先填写名称、地址，选择自动、WebSocket、HTTP 或轮询连接并填写可选资产信息，再保存并生成 30 分钟有效的安装命令。安装包由主控提供，支持 Linux systemd、amd64 / arm64；缺包时明确提示。
- 地区、服务商、探针、费用、到期日、流量额度和其他高级参数通过接入后的“编辑”补充。
- Agent 支持 WebSocket、HTTP 直连、Pull（轮询）与 Auto（自动）。自动按 WS → HTTP → Pull 回退，并定期重试 WS；HTTP 需要主控能访问 Agent 管理端口。WS / Pull 单独使用时不监听管理端口。卡片与编辑页可选择模式，配置通道与实际通道分开显示；已升级 Agent 经认证通道接收设置、持久化后切换，旧版需升级。Xray 仍仅保留内嵌模式。
- 自有探针、登录回接及外部 Komari 1.2.5-fix2 观测接入保持原有范围。探针来源不是服务器管理接入方式。

## 受管入站

- `/inbounds` 仅支持 **VLESS + TCP + REALITY**，默认 Flow 为 `xtls-rprx-vision`。协议和传输固定，保留端口、监听地址、REALITY 目标、SNI、密钥、Short ID、Flow、嗅探和状态配置。
- 主控的入站保存、配置编译、用户同步与受管订阅节点使用同一协议限制；高级 JSON 覆盖不能替换协议、传输、安全方式或成员凭据。
- 旧的不兼容记录保留，可停用或删除。编辑中的转换操作只修改待保存表单，并清空旧的协议与传输覆盖；补全 REALITY 参数并保存后才更新主控。

## 节点与出站代理

- 节点页面采用折叠导入区、集中操作栏、协议/标签数量筛选和节点表格。表格直接提供显示信息编辑、受管入站/路由入口、手动 TCP 测试、连接配置、URI 复制及临时订阅入口。协议标签反映实际记录，不代表新增协议支持。
- 支持排序模式、批量标签、带预览的批量改名和地区 Emoji；删除单项、所选或全部节点均先展示明确范围并确认。外部订阅同步及测速仅手动触发。
- 侧边栏的节点、外部订阅、订阅管理、临时订阅、规则与模板、套餐、成员及个人账户入口统一归入“工作区”；保留“运维”分类及原有角色权限。

- `/nodes` 新增节点固定为 **VLESS + TCP + REALITY**，手动接入使用完整的 `vless://` 链接。主控按实际协议、传输、安全方式及连接参数校验，不能仅修改显示标签绕过限制。
- 外部订阅和联邦接入遵循相同限制，不兼容节点不进入新的导入与订阅分发。Clash、V2Ray、sing-box 等为文件或客户端格式，不代表允许其他代理协议。
- `/outbounds` 的代理类型仅提供 VLESS TCP REALITY；直连与阻断仍是独立的路由操作，端口转发通过“扩展能力 → 转发与隧道”管理。出站的 JSON 配置也需通过主控校验。
- 旧节点与出站记录保留，支持停用、删除或使用完整的受支持配置重新保存。旧套餐中的节点引用不自动清除，网站标注不再支持，管理员可主动移除。
- 内部 API / 测试监听与系统网络运维保留；Agent 继续使用现有核心运行时。原始核心配置属于高级运维入口，不能据此宣称节点库支持其他代理协议。

## 路由与运维

路由新增可视化编辑、顺序管理、入站作用域、默认出站与四种均衡策略，具体边界见 [路由功能](XRAY-ROUTING.md)。核心版本始终来自 ASWired Agent 的实际 Xray 上报，与 Komari 主机观测分开。Agent 已有本地维护升级脚本，尚无主控触发的 Agent 自更新任务。

## 邀请码注册

- 管理员在“成员与权限 → 管理注册邀请码”生成一次性注册邀请码，可填写备注和 1–90 天有效期（默认 7 天），查看使用状态并撤销未使用邀请码。
- 登录页提供“使用邀请码注册”，注册后自动登录普通用户账户。注册邀请不附带套餐；套餐兑换码仍走原有兑换流程。
- 邀请码原文仅生成时返回，主控只保存摘要；账户、成员记录和邀请码消耗在同一事务提交。并发使用只允许一个成功，用户名重复不消耗邀请码。
- 注册使用现有密码规则、请求限频、人机验证和隐藏入口保护，客户端不能指定管理员角色。普通成员不能生成、查看或撤销注册邀请。

## REALITY 目标池扫描来源

- 管理员可从主控或在线、声明 `reality_scan` 能力的 ASWired Agent 发起扫描。Agent 通过现有加密 WebSocket 任务通道执行，结果记录实际服务器来源。
- 手动“添加目标 / 提交目标”表单及 `POST /api/reality-targets` 已删除。新增目标只能由管理员扫描合格后导入，仍需审核才能启用；普通用户无扫描、导入或池管理权限。
- 扫描限制公网目标、每批 128 个地址及并发上限，验证 TLS 1.3、h2、X25519 和证书。Agent 从原 IP 复测发现的 SNI，禁止私网或 DNS 重绑定绕过。
- 取消 Agent 扫描会停止主控等待；已送达的 Agent 任务可能继续完成，但不会自动导入。过期任务由 Agent 拒绝，扫描证据最多保留 15 分钟供导入。

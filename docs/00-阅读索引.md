# ASWired 完整设计与原型

版本：设计 1.5 / 2026-09-15。目标为除PRO商业授权外采用妙妙屋 X 的设计和公开行为，全部功能不设付费墙；保留用户明确的 ASWired 品牌、固定深色和外部探针仅支持 Komari 1.2.5-fix2 的差异；保留自有探针及登录回接。真实管理 API、Agent、Komari 接入、支付渠道、订阅转换器尚未实现，设计覆盖不等于实现完成。

## 当前设计决定

准备将项目划分为网站、主控后端、子 Agent 三个独立私有仓库。本轮完整方案包含普通与 PRO 能力，先评审设计，尚未拆仓或实现 Agent。本轮先看主控如何采用妙妙屋的实际公开设计，再逐项核对Agent配合：

- [主控后端详细设计](19-主控后端详细设计.md)：一手来源对照、技术部署、认证、套餐、配置、计量、订阅、运维、联邦、探针及恢复。
- [主控全功能验收清单](20-主控全功能验收清单.md)：168项逐条列明主控/Agent/网站职责、公开依据与待执行验证；结构化版本为 `reference/aswired-server-coverage.json`。

- [完整功能与 PRO 对齐矩阵](15-完整功能与PRO对齐矩阵.md)：原146项逐项归属、目标、阶段和验收，以及PRO细化；机器可读版本位于 `docs/reference/aswired-alignment.json`。
- [子 Agent 详细设计](13-子Agent详细设计.md)：同进程内嵌/独立外置核心、Token与主控公钥、三种连接及固定版本行为核对。
- [三仓拆分与协作设计](14-三仓拆分与协作设计.md)：仓库命名、职责、契约归属、独立开发和迁移顺序。
- [增强运行时与 PRO 执行设计](16-增强运行时与PRO执行设计.md)：用户/节点限速、连接/IP、自动规则、Vision/多协议通路与计量。

- [自有探针与登录回接设计](18-自有探针与登录回接设计.md)：原生采集、内置/独立展示、双来源、历史与密码/Passkey登录回接；用户认证明确使用JWT，传输、到期与回接按上游公开说明及固定版本样例核对。

用户已确定采用上游设计且无PRO付费墙；本轮据此整理主控v0.1及配套Agent v0.3方案，仍未开始实现。P0–P6仅划分实现顺序，不能删减范围或用自拟替代架构改变公开行为。下列既有文档保留参考事实与早期业务草案；当前实施范围以第13–20份修订稿为准。旧草案中自行新增的车主角色、多工作区、审批、AA及独立账务流程不自动成为对齐要求。上游未公开部分不臆造内部实现，保留功能目标与验收依赖。

## 基线与范围

妙妙屋 X 以稳定 v0.5.4 和预发布 v0.5.5-beta.6 的官方说明共同核对，历史拼车市场已在新预发布移除，保留审计记录，不重新引入其入口或自行扩展成本分摊。3X-UI 以 v3.8.0 源码核对。妙妙屋 X 公开仓库未提供完整应用源码，未知内部行为在矩阵中保留“待实机验收”，不宣称做到闭源实现的逐行等价。

自有探针、内置/独立部署页面及登录回接全部保留；仅外部第三方探针接入固定为 Komari **1.2.5-fix2**。原生与 Komari 可并存，按显式来源绑定构建公开白名单投影。Xray 配置、账务计量与主机观测各自独立；公开功能对齐不等于兼容未公开的上游内部协议。

本地入口：<http://localhost:5174/>。前端数据使用保留示例域名和文档 IP；操作写入浏览器本地存储。UI 的管理员/成员视图不是安全隔离，真实隔离必须由后端实施。

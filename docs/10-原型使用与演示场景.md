# 原型使用与演示场景

> 早期业务草案说明：本文仍保留旧版业务模型或原型交互供参考。自行提出的车主/多租户、AA账本、人工审批及付款流程不是本轮新增要求；角色、套餐和续费等实际行为以[第15份当前矩阵](15-完整功能与PRO对齐矩阵.md)及固定版本核对为准，不据旧稿另设流程。

## 启动

进入桌面 `RayNo1/frontend`：首次 `pnpm install`，然后 `pnpm dev`，打开 <http://localhost:5174/>。本次已安装依赖并启动。端口固定为5174，不占用之前网站的5173。`pnpm check` 检查类型，`pnpm build` 构建正式产物；构建后使用 `HOST=127.0.0.1 PORT=5174 node build` 的等效环境配置启动。

## 演示路线

1. 首页查看服务器、流量和车队，切换7天/30天趋势。点击香港服务器进入资源详情，查看配置版本与接入说明。
2. 服务器页新增“测试节点”，填写文档IP和成本，保存。搜索后查看详情，执行模拟配置发布，再到任务页看执行步骤。
3. 套餐页编辑“亚太日常”，选择节点和流量额度，保存。已发布/草稿状态可切换。
4. 订阅页创建成员订阅，可选择多个套餐；获取订阅时切换客户端、显示链接、复制、二维码、配置预览、下载样例和轮换演示令牌。
5. 拼车页创建车队或进入亚太轻量车，预留成员席位；新成员与待支付账单同时出现。已满车队不能继续添加。费用试算例如100元/3席，结果33.34、33.33、33.33，总和100元。
6. 成员门户切换林舟/陈夏等样例，在待支付账单上提交续费声明。随后账单页筛选待核销，由演示车主确认实收，状态变已核销。
7. 路由与DNS输入非法JSON，点击校验看到错误；恢复合法对象后保存草稿并模拟发布，在任务页查看结果。模板仅做语法校验，不宣称通过Xray运行校验。
8. 设置页调整工作区偏好、导出本地演示备份；全站使用固定深色外观；扩展能力查看联邦、站点、测速、Bot、迁移与隔离脚本形态。
9. 设计页按关键词搜索146项覆盖矩阵，下载完整设计文档。
10. 设置页查看固定的 Komari 1.2.5-fix2 探针配置与公开字段，再到公开探针页查看白名单展示样例；这些操作只演示设置和投影，不会检测真实 Komari 服务。

## 明确限制

- 数据保存在当前浏览器 localStorage，可从系统维护恢复；没有真实登录和后端安全边界。
- 演示地址都是 example.test/文档IP；复制链接不会获得真实代理服务。
- 10种格式全部有选择入口；Clash/Stash给出YAML结构、sing-box/V2Ray给出JSON说明，其余展示通用预览。它们不是完整生产转换器，不承诺可连接。
- 短延时任务只改变演示状态，未检测真实服务器、投递外部消息、续期证书或执行用户脚本。
- 初始车队部分席位预占，成员名单仅列代表样例；新加入成员会完整记入本地列表。
- 模型中的价格/用量/日期为固定场景样例；没有支付接入。成员声明与演示核销不发生资金流动。
- 配额模式、离线策略、退款、候补、真正的MFA/联邦等在设计文档中完整定义，前端只展示部分表单与路径。
- 设计包含自有探针与登录回接，仅外部第三方接入限 Komari 1.2.5-fix2。当前原型仍没有真实采集/连接、版本校验、指标同步或登录回接；公开数据为合成样例，按[自有探针](18-自有探针与登录回接设计.md)和[Komari接入](12-Komari探针接入设计.md)分别验收。

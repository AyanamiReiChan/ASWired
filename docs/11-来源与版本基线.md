## 用户 JWT 认证

2026-09-15核对[妙妙屋官方用户管理文档](https://miaomiaowux.com/docs/en/users/#authentication)：登录后取得JWT，通过MM-Authorization请求头认证，过期需重新登录。用户明确ASWired也采用JWT；本项目按[第18份0.3](18-自有探针与登录回接设计.md)核对签名、claims、浏览器存储和注销，撤回自拟刷新架构。README关于JWT_SECRET/HMAC及随机token的差异保留为证据冲突，ASWired按用户要求固定JWT。

## Komari 探针

- 唯一外部第三方探针供应方：[komari-monitor/komari](https://github.com/komari-monitor/komari)。固定 tag 为 [1.2.5-fix2](https://github.com/komari-monitor/komari/releases/tag/1.2.5-fix2)（无 `v` 前缀），短 commit `2f70b44`。
- 该版本发布说明明确 `common:getNodes` 的多节点响应为 UUID-keyed 字典；单 UUID 查询为单对象。ASWired 按稳定 UUID 绑定服务器，不按数组位置、名称或 IP 关联。
- ASWired 保留自有采集、内置/独立探针页面及登录回接，具体设计见[第18份](18-自有探针与登录回接设计.md)。外部供应商只支持 Komari，不接入其他供应商；原146项上游事实保持不变，不宣称复用上游未公开会话或采集协议。
- 本次核对固定 tag 的公开接口和源码，未运行 Komari 服务或建立真实连接。指标字段、认证部署形态、历史粒度与刷新策略须在 1.2.5-fix2 实机验收，不将最新文档能力回填到该版本。
- 固定源码的路由、RPC、版本响应和认证链接，以及已核实的响应差异，见 [Komari探针接入设计](12-Komari探针接入设计.md)。

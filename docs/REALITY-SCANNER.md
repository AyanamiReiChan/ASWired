# REALITY 目标扫描

管理员进入 **REALITY 目标池 → 扫描目标**，可扫描域名、IP 或 CIDR 网段；留空使用内置候选站点。多个目标可用换行、空格或逗号分隔，端口默认为 443。IPv6 指定端口时使用 `[地址]:端口`。

## 使用流程

1. 输入候选目标并开始扫描。每批最多 128 个地址，单个网段也不得超过 128 个地址；超限会要求缩小范围。
2. 查看 TLS 1.3、HTTP/2（h2）、X25519、证书、延迟和失败原因。结果优先展示合格目标，可按延迟或地址排序。
3. 选择合格项，点击“加入待审核”。主控将已确认的 SNI 域名加入允许列表，保存原始目标地址与端口，已有目标不会重复创建。跳过已有目标不会恢复其已撤回的域名；新增同域名的其他目标时，旧目标也不会自动恢复启用。
4. 回到目标池审核启用。扫描结果在 15 分钟内可加入；审核也需要有效的近期探测。超过时限时重新探测后再审核。
5. 在入站编辑的 REALITY 配置中选择已审核目标，自动填写目标地址和已验证的 SNI。

## 检测范围

- 扫描从**主控**发起，延迟与可达性不代表 Agent 所在网络。候选目标的网络条件可能变化。
- 扫描只连接公网，不访问回环、私网、链路本地或保留地址。
- IP / 网段扫描先读取证书中的具体域名，再以该域名作为 SNI 对同一 IP 和端口进行第二次握手；只取得证书不算验证成功。
- 域名证书、TLS 1.3、h2 和 X25519 均通过才标记合格。结果只是当前握手兼容性检查，不保证目标长期可用。
- 导入使用主控保存的扫描记录及结果编号，浏览器不能自行提交“已通过”的探测证据。
- 普通成员贡献目标的账户年龄、每日配额及审核流程保持原有规则；扫描与批量加入仅供管理员使用。

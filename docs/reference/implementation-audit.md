# ASWired 当前实现与差异

更新：2026-09-16。网站、主控、Agent 均使用真实接口与执行结果；三个 GitHub 仓库保持私有。

当前接入范围：**仅 ASWired Agent**。面板 API 适配不在当前范围，早期设计及来源只保留追溯。168 项目标原本没有独立的面板适配条目，本次不改变目标编号和既有状态计数；范围说明见 [当前实施范围](../CURRENT-SCOPE.md)。以下验证记录保留其原始版本与日期，不替代后续变更验收。

**这不是全部功能完成声明。** 168项公开功能目标中，53项有列明子集的验证证据，37项已实现但仍待完整验收，77项仍有明确缺项，1项按范围排除。通过子集测试不代表整条上游验收标准或生产平台全部通过。

完整实现范围、文件及测试证据见 [机器可读核对表](implementation-audit.json)。`server/` 和 `agent/` 分别指独立 ASWired-Server、ASWired-Agent 仓库。

## 环境与兼容边界

- 尚未执行 Linux kernel WireGuard、systemd/OpenRC、Docker host、REALITY/Vision splice 实机测试；镜像构建通过不代表容器部署验收。
- PostgreSQL 16 已通过基础隔离集成测试，成员删除/最后管理员保护及成员配额的完整 PostgreSQL 并发矩阵仍待验证。
- 前端测试路径作为证据，完整浏览器/各客户端矩阵需由集成人员确认。
- 未公开协议采用用户允许的 ASWired 原创等效实现，不承诺妙妙屋私有 Agent、客户端信任或旧备份格式互通。
